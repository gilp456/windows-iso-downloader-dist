# Content, provider, and link concerns

This repository distributes downloader code and metadata. It does not host Microsoft installation-media payloads.

To request a catalog correction, provider removal, link removal, or trademark correction, open a [content-removal request](https://github.com/gilp456/windows-iso-downloader-dist/issues/new?template=content-removal.yml) containing:

1. The exact catalog record, URL, provider, filename, or project text at issue.
2. The requested correction or removal.
3. A concise explanation of the rights, provider policy, or factual issue involved.
4. A public contact method suitable for follow-up.

GitHub Issues are public. Do not post private identification documents, confidential contracts, private keys, access tokens, or personal information. Formal copyright, trademark, or private-information requests that require confidential material should use GitHub's applicable [content-removal process](https://docs.github.com/en/site-policy/content-removal-policies/submitting-content-removal-requests).

Credible requests will be reviewed as soon as practical. A disputed provider adapter, catalog entry, or link may be disabled while the concern is reviewed. Any correction applies prospectively to later catalog refreshes or releases; copies already downloaded by users remain outside this project's control.
